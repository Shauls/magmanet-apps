Privacy Policy — Split It (מתחלקים)

Last updated: 2026-10-24

Split It is made by Magmanet. In short: your groups stay on your device. The app also sends anonymous usage statistics, which you can turn off.

What we collect

By default, only anonymous usage statistics (see below). Split It has no sign-up, no accounts, no advertising and no tracking. We never sell or share your data.

Where your data is stored

Your groups, people's names and avatars, expenses, payments, dinner bills, exchange rates and settings are saved only on your device, in the app's private storage. Uninstalling the app or using Settings → Delete all groups removes them.

You choose when to share something: a summary text, a CSV file, or a group file or code. These go through Android's share sheet to the app and people you pick (for example WhatsApp). Magmanet never receives them. The Copy backup feature copies your data as text to your clipboard; where you paste it is up to you.

Money

Split It only calculates who owes whom. It never moves money, connects to no bank or payment app, and never asks for card or account details.

Internet use

  • Exchange rates (optional): the app downloads public ECB euro reference rates from Magmanet's server (/v1/fx, EU, Contabo). The request carries no identifier, and the server stores nothing about the caller. You can turn this off in Settings ("Update rates online") and type your own rates.
  • Update check: once a day the app asks the Magmanet server whether a newer version exists. The request carries only the app name, its version and how it was installed. If the server is unavailable, the app reads the public version file from GitHub Pages (GitHub may see your IP address). You can turn this off in Settings.
  • Anonymous usage statistics: see below.

Anonymous usage statistics

Split It sends anonymous usage statistics over HTTPS (a short daily ping, plus batched usage events) to Magmanet's own server in the EU (Contabo). They include the app name and version, Android version, phone manufacturer and model, language, how the app was installed, a random install ID, and which screens and features are used (for example "expense added" or "summary shared"). They never include names, amounts, group contents or anything you type. The ID is hashed on the server, no IP address is stored, and raw data is deleted after 400 days. The data is never used for ads and never sold or shared.

It's on by default. You can turn it off in Settings ("Share anonymous usage statistics"); doing so stops sending and deletes the random ID and any unsent events.

Permissions

  • Internet: for exchange rates, the update check and anonymous statistics.

No location, camera, microphone, contacts, storage or notification permissions are requested. Choosing a group file to import uses Android's file picker, which gives the app only the file you pick.

Children

Split It is not directed at children.

Changes and contact

If this policy changes, we'll update the date above. Questions: https://github.com/Shauls/magmanet-apps/issues
