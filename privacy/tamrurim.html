מדיניות פרטיות — תמרורים

עודכן: אוקטובר 2026

האפליקציה "תמרורים" פועלת כולה על המכשיר.

  • אין איסוף מידע. האפליקציה אינה אוספת, שולחת או משתפת מידע אישי. אין בה פרסומות, חשבונות משתמש או כלי ניתוח (analytics).
  • התקדמות הלימוד (תשובות, מבחנים, הגדרות) נשמרת בקובץ על המכשיר בלבד. אם גיבוי המכשיר של Google מופעל, הקובץ נכלל בגיבוי האוטומטי של Android, בכפוף להגדרות החשבון שלך.
  • גיבוי ושיתוף ידניים מתבצעים רק לפי בחירתך: שמירת קובץ גיבוי למיקום שבחרת, או שיתוף סיכום התקדמות דרך אפליקציה שבחרת.
  • הרשאות: התראות — לתזכורת היומית, רק אם הפעלת אותה; הפעלה מחדש של המכשיר — כדי לתזמן מחדש את התזכורת; רטט — למשוב על תשובה.
  • בדיקת עדכונים. פעם ביום האפליקציה בודקת אם יש גרסה חדשה, על ידי הורדת קובץ גרסאות ציבורי מ-GitHub Pages (shauls.github.io). לא נשלח שום מידע אישי; כמו בכל פנייה לאתר, GitHub עשויה לראות את כתובת ה-IP של המכשיר. אפשר לכבות את הבדיקה בהגדרות. מלבד זאת האפליקציה אינה משתמשת באינטרנט. הקראת שאלות (אם הופעלה) נעשית במנוע ההקראה של המכשיר.
  • הרשאת אינטרנט משמשת רק לבדיקת העדכונים.
  • מקור השאלות: מאגר השאלות הציבורי שפורסם במאגר המידע הפתוח data.gov.il. האפליקציה אינה אפליקציה רשמית ואינה קשורה למשרד התחבורה.

Privacy policy — Tamrurim

Updated: October 2026. Application id com.magmanet.tamrurim.

The app works entirely on the device. It collects, sends and shares no personal data, and has no ads, accounts or analytics. Learning progress is stored in a file on the device (included in Android's automatic Google backup if the user has it enabled). Manual backup and progress sharing happen only when the user chooses. Permissions: notifications (optional daily reminder), boot completed (to reschedule it), vibration (answer feedback), internet (only for the update check). Once a day the app checks whether a newer version exists by downloading a public version file from GitHub Pages (shauls.github.io). The request carries no personal data or identifiers; GitHub may see the device's IP address, as with any web request. The check can be turned off in Settings. The app uses the internet for nothing else; read-aloud (if turned on) uses the device's own text-to-speech engine. Questions come from the public theory-test question pool published on the data.gov.il open-data portal; the app is not an official app and is not affiliated with the Ministry of Transport.

Questions? Open an issue at https://github.com/Shauls/magmanet-apps/issues
