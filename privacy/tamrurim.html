מדיניות פרטיות — תמרורים

עודכן: אוקטובר 2026

האפליקציה "תמרורים" פועלת כולה על המכשיר.

  • אין איסוף מידע אישי. האפליקציה אינה אוספת, שולחת או משתפת מידע אישי. אין בה פרסומות או חשבונות משתמש. היא שולחת רק נתוני שימוש אנונימיים (ראו בהמשך), ואפשר לכבות אותם.
  • התקדמות הלימוד (תשובות, מבחנים, הגדרות) נשמרת בקובץ על המכשיר בלבד. אם גיבוי המכשיר של Google מופעל, הקובץ נכלל בגיבוי האוטומטי של Android, בכפוף להגדרות החשבון שלך.
  • גיבוי ושיתוף ידניים מתבצעים רק לפי בחירתך: שמירת קובץ גיבוי למיקום שבחרת, או שיתוף סיכום התקדמות דרך אפליקציה שבחרת.
  • הרשאות: התראות — לתזכורת היומית, רק אם הפעלת אותה; הפעלה מחדש של המכשיר — כדי לתזמן מחדש את התזכורת; רטט — למשוב על תשובה.
  • בדיקת עדכונים. פעם ביום האפליקציה בודקת אם יש גרסה חדשה יותר בפנייה לשרת של Magmanet (באיחוד האירופי, אצל Contabo) — הבקשה כוללת רק את שם האפליקציה, מספר הגרסה שלה ודרך ההתקנה (מהאתר/מ-Google Play); השרת סופר בדיקות לפי אפליקציה וגרסה באופן מצטבר בלבד, ולא שומר מזהים או כתובת IP; אם השרת לא זמין, האפליקציה מורידה במקום זאת את קובץ הגרסאות הציבורי מ-GitHub Pages (GitHub עשוי לראות את כתובת ה-IP שלך). אפשר לכבות את הבדיקה בהגדרות. מלבד זאת ומלבד נתוני השימוש האנונימיים, האפליקציה אינה משתמשת באינטרנט. הקראת שאלות (אם הופעלה) נעשית במנוע ההקראה של המכשיר.
  • נתוני שימוש אנונימיים. האפליקציה שולחת נתוני שימוש אנונימיים (פינג קצר פעם ביום; אירועי שימוש לכל היותר כמה פעמים ביום, במנות) בחיבור מוצפן (HTTPS) לשרת של Magmanet, שמאוחסן באיחוד האירופי (אצל Contabo), ולא ל-Google או לכל צד שלישי אחר: שם האפליקציה והגרסה שלה, גרסת Android, השפה, דרך ההתקנה (מ-Google Play, מהאתר או ממקור אחר), מזהה התקנה אקראי (שהאפליקציה יוצרת בזמן ההתקנה, ואינו מזהה של המכשיר), ואירועי שימוש אנונימיים (באילו מסכים ותכונות משתמשים ולכמה זמן), בלי שום תוכן אישי. בשרת המזהה עובר גיבוב (hash), כתובת ה-IP לא נשמרת, והנתונים הגולמיים נמחקים אחרי 400 יום. הם משמשים רק לספירת משתמשים פעילים ולשיפור האפליקציה, אף פעם לא לפרסום או ליצירת פרופילים, ולעולם לא נמכרים או משותפים. השליחה פעילה כברירת מחדל; אפשר לכבות אותה בהגדרות ("שיתוף נתוני שימוש אנונימיים"), והכיבוי עוצר את השליחה מיד ומוחק מהטלפון את המזהה האקראי ואת אירועי השימוש שעוד לא נשלחו.
  • הרשאת אינטרנט משמשת רק לבדיקת העדכונים ולנתוני השימוש האנונימיים.
  • מקור השאלות: מאגר השאלות הציבורי שפורסם במאגר המידע הפתוח data.gov.il. האפליקציה אינה אפליקציה רשמית ואינה קשורה למשרד התחבורה.

Privacy policy — Tamrurim

Updated: October 2026. Application id com.magmanet.tamrurim.

The app works entirely on the device. It collects, sends and shares no personal data, and has no ads or accounts; it only sends anonymous usage statistics (below), which can be turned off. Learning progress is stored in a file on the device (included in Android's automatic Google backup if the user has it enabled). Manual backup and progress sharing happen only when the user chooses. Permissions: notifications (optional daily reminder), boot completed (to reschedule it), vibration (answer feedback), internet (only for the update check and the anonymous usage statistics). Once a day the app checks for a newer version by asking the Magmanet server (EU, Contabo) — the request contains only the app name, its version number and how it was installed (site/Google Play); the server counts checks per app and version in aggregate, stores no identifiers and no IP address; if the server is unavailable the app downloads the public version file from GitHub Pages instead (GitHub may see your IP address). The check can be turned off in Settings. Anonymous usage statistics: the app sends (a short ping once a day; usage events a few times a day at most, batched), over HTTPS to Magmanet's own server hosted in the EU (Contabo), not to Google or any third party, the app name and version, Android version, language, how the app was installed (Google Play, the website or elsewhere), a random install ID (made by the app at install time, not a device identifier) and anonymous usage events (which screens and features are used and for how long), with no personal content. The ID is hashed on the server, no IP address is stored, and raw data is deleted after 400 days. It is used only to count active users and improve the app, never for ads or profiling, and never sold or shared. It is on by default and can be turned off in Settings ("שיתוף נתוני שימוש אנונימיים"); turning it off stops sending immediately and deletes the random ID and unsent usage events from the phone. The app uses the internet for nothing else; read-aloud (if turned on) uses the device's own text-to-speech engine. Questions come from the public theory-test question pool published on the data.gov.il open-data portal; the app is not an official app and is not affiliated with the Ministry of Transport.
