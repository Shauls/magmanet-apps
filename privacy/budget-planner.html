Privacy Policy — Budget Planner

Last updated: 2026-10-18

Budget Planner is made by Magmanet. This policy explains what the app does with your information. The short version: your data stays on your device; the app only sends anonymous usage statistics, which you can turn off.

What we collect

Budget Planner has no accounts, no advertising and no tracking. The only thing we collect is anonymous usage statistics (see below), which you can turn off. We never see, sell or share your data.

Where your data is stored

Everything you enter is saved only on your device, in the app's private storage. It is removed when you uninstall the app.

The app's Copy backup feature (Settings → Your data) copies your data as text to your clipboard, so you can keep it somewhere you choose. Where you paste it is up to you; the app never uploads it.

Internet use

Budget Planner works entirely offline. It goes online only to send anonymous usage statistics (see below) and to check for updates. Once a day the app checks for a newer version by asking the Magmanet server (EU, Contabo) — the request contains only the app name, its version number and how it was installed (site/Google Play); the server counts checks per app and version in aggregate, stores no identifiers and no IP address; if the server is unavailable the app downloads the public version file from GitHub Pages instead (GitHub may see your IP address). If a newer version exists, the app shows a notice and you choose whether to open the download link. You can turn this off in Settings ("Check for updates automatically").

Anonymous usage statistics

Budget Planner sends anonymous usage statistics over HTTPS (a short ping once a day; usage events a few times a day at most, batched) to Magmanet's own server, hosted in the EU (Contabo), not to Google or any other third party. It sends the app name and version, your Android version, your language, how the app was installed (from Google Play, the website or elsewhere), a random install ID, and anonymous usage events (which screens and features are used and for how long). The random ID is made by the app when it is installed; it is not a device identifier. No personal content is sent.

On the server the ID is hashed and no IP address is stored. Raw data is deleted after 400 days. It is used only to count active users and improve the app, never for advertising or profiling, and it is never sold or shared.

This is on by default. You can turn it off in Settings ("Share anonymous usage statistics"). Turning it off stops sending immediately and deletes the random ID and any unsent usage events from your phone.

Changes

If this policy changes, we'll update the date above and publish the new version at the same address.
