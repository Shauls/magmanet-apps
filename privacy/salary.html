עודכן לאחרונה: 18/10/2026

את האפליקציה "מחשבון שכר" (com.magmanet.salary) מפתחת Magmanet. המסמך הזה מסביר מה האפליקציה עושה במידע שלכם. בקיצור: המידע שלכם נשאר במכשיר שלכם. האפליקציה שולחת רק נתוני שימוש אנונימיים, ואפשר לכבות אותם.

איזה מידע אנחנו אוספים

אנחנו אוספים רק נתוני שימוש אנונימיים (ראו בהמשך), ואפשר לכבות אותם. באפליקציה אין: - חשבונות משתמש - פרסומות - מעקב

אנחנו לא רואים את המידע שלכם, לא מוכרים אותו ולא משתפים אותו.

איפה המידע נשמר

כל מה שאתם מזינים נשמר רק באחסון הפרטי של האפליקציה במכשיר: - נתוני שכר - פרופילים אישיים (מצב משפחתי, שנות לידה של ילדים, תאריכי עלייה או שחרור, תואר, יישוב) - תרחישים שמורים

כל החישובים נעשים במכשיר. הסרת האפליקציה מוחקת את כל המידע.

אינטרנט

האפליקציה עובדת גם בלי אינטרנט, עם נתוני המס המובנים בה. היא מתחברת לרשת רק לארבע מטרות:

  1. עדכון נתוני המס: לכל היותר פעם ביום, ובכל פעם שתלחצו "בדיקת עדכון נתונים". - האפליקציה מורידה קובץ נתונים ציבורי מ-GitHub Pages (shauls.github.io). הקובץ כולל מדרגות מס, שיעורי ביטוח לאומי, תקרות וקישורים רשמיים.
  2. בדיקת גרסה חדשה: פעם ביום האפליקציה בודקת אם יש גרסה חדשה יותר בפנייה לשרת של Magmanet (באיחוד האירופי, אצל Contabo) — הבקשה כוללת רק את שם האפליקציה, מספר הגרסה שלה ודרך ההתקנה (מהאתר/מ-Google Play); השרת סופר בדיקות לפי אפליקציה וגרסה באופן מצטבר בלבד, ולא שומר מזהים או כתובת IP; אם השרת לא זמין, האפליקציה מורידה במקום זאת את קובץ הגרסאות הציבורי מ-GitHub Pages (GitHub עשוי לראות את כתובת ה-IP שלך). - אפשר לכבות את הבדיקה בהגדרות.
  3. דפי מידע רשמיים: כשאתם בוחרים קישור במסך "מידע רשמי" או מקור של נתון, הדף נפתח בדפדפן בתוך האפליקציה. - הדפים שייכים לאתרים כמו gov.il, btl.gov.il ו-kolzchut.org.il, ומדיניות הפרטיות שלהם חלה עליהם.
  4. נתוני שימוש אנונימיים: פינג קצר פעם ביום, ואירועי שימוש לכל היותר כמה פעמים ביום (במנות); ראו בסעיף הבא.

בסעיפים 1 ו-2 לא נשלח שום מידע עליכם או על המכשיר: לא נתוני שכר, לא מידע אישי ולא מזהים. בהורדה מ-GitHub Pages, כמו בכל בקשה ברשת, השרת יכול לראות את כתובת ה-IP של המכשיר.

נתוני שימוש אנונימיים

האפליקציה שולחת נתוני שימוש אנונימיים (פינג קצר פעם ביום; אירועי שימוש לכל היותר כמה פעמים ביום, במנות) בחיבור מוצפן (HTTPS) לשרת של Magmanet, שמאוחסן באיחוד האירופי (אצל Contabo), ולא ל-Google או לכל צד שלישי אחר. נשלחים: שם האפליקציה והגרסה שלה, גרסת Android, יצרן ודגם הטלפון (למשל Samsung SM-S911B; לא השם שנתתם לטלפון), השפה, דרך ההתקנה (מ-Google Play, מהאתר או ממקור אחר), מזהה התקנה אקראי, ואירועי שימוש אנונימיים (באילו מסכים ותכונות משתמשים ולכמה זמן). המזהה האקראי נוצר על ידי האפליקציה בזמן ההתקנה, והוא אינו מזהה של המכשיר. לא נשלח שום תוכן אישי (לא נתוני שכר ולא פרטי פרופיל).

בשרת המזהה עובר גיבוב (hash), וכתובת ה-IP לא נשמרת. הנתונים הגולמיים נמחקים אחרי 400 יום. הם משמשים רק לספירת משתמשים פעילים ולשיפור האפליקציה, אף פעם לא לפרסום או ליצירת פרופילים, ולעולם לא נמכרים או משותפים.

השליחה פעילה כברירת מחדל. אפשר לכבות אותה בהגדרות ("שיתוף נתוני שימוש אנונימיים"). הכיבוי עוצר את השליחה מיד ומוחק מהטלפון את המזהה האקראי ואת אירועי השימוש שעוד לא נשלחו.

שיתוף שאתם יוזמים

המידע שאתם מזינים יוצא מהמכשיר רק כשאתם בוחרים לשתף אותו, ורק ליעד שאתם בוחרים:

  • שיתוף פירוט השכר (טקסט או PDF): האפליקציה פותחת את תפריט השיתוף של המערכת. אתם בוחרים את האפליקציה ואת הנמען.
  • הדפסה: נעשית דרך שירות ההדפסה של המכשיר.
  • העתקת פירוט או גיבוי: הטקסט מועתק ללוח, ואתם מחליטים היכן להדביק אותו.

הרשאות

  • אינטרנט (INTERNET): משמשת רק למטרות שתוארו בסעיף "אינטרנט".
  • הרשאה פנימית של AndroidX: DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION נוספת אוטומטית, ואינה ניגשת למידע.

האפליקציה לא מבקשת גישה למיקום, לאנשי קשר, למצלמה, למיקרופון או לקבצים.

ילדים

האפליקציה מיועדת למבוגרים (18+). איננו אוספים מידע אישי מאף אחד, כולל ילדים (נתוני השימוש שתוארו למעלה הם אנונימיים).

הבהרה

החישובים משוערים ולצורכי מידע בלבד. הם אינם מהווים ייעוץ מס או ייעוץ משפטי. האפליקציה אינה קשורה לרשות המסים, לביטוח הלאומי או לכל גוף ממשלתי.

English summary

  • We collect only anonymous usage statistics. The app has no accounts, ads or tracking.
  • Storage: salary figures, personal profiles (for credit points) and saved scenarios are kept only in the app's private storage. Uninstalling the app deletes them.
  • Internet, used for four things only:
  • downloading the public tax-rules file (at most once a day, or when you tap "check for data update");
  • the daily update check, which you can turn off in Settings. Once a day the app checks for a newer version by asking the Magmanet server (EU, Contabo) — the request contains only the app name, its version number and how it was installed (site/Google Play); the server counts checks per app and version in aggregate, stores no identifiers and no IP address; if the server is unavailable the app downloads the public version file from GitHub Pages instead (GitHub may see your IP address);
  • opening official pages you choose, in an in-app browser tab;
  • anonymous usage statistics (below). None of these sends anything about you or your device (no salary figures, no identifiers). GitHub Pages can see the device's IP address during a download, as with any web request.
  • Anonymous usage statistics: the app sends (a short ping once a day; usage events a few times a day at most, batched), over HTTPS to Magmanet's own server hosted in the EU (Contabo), not to Google or any third party: the app name and version, Android version, phone manufacturer and model (never the name you gave the phone), language, how the app was installed (Google Play, the website or elsewhere), a random install ID (made by the app at install time, not a device identifier), and anonymous usage events (which screens and features are used and for how long). No personal content (no salary figures or profile details). The ID is hashed on the server, no IP address is stored, and raw data is deleted after 400 days. Used only to count active users and improve the app, never for ads or profiling, never sold or shared. On by default; turn it off in Settings ("שיתוף נתוני שימוש אנונימיים"), which stops sending immediately and deletes the random ID and unsent usage events from the phone.
  • Sharing you start: text or PDF breakdowns leave the device only when you share, print or copy them.
  • Permissions: INTERNET, plus the app-private com.magmanet.salary.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION that AndroidX adds automatically. No runtime permissions are requested.
  • Not advice; not affiliated: results are estimates for information only. The app is not affiliated with any government body.
