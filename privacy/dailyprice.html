Privacy Policy — What's the Price? (כמה זה עולה?)

Last updated: 2026-10-24

What's the Price? is made by Magmanet. The short version: your games stay on your device. The app asks our server for supermarket prices (sending only product barcodes) and sends anonymous usage statistics, which you can turn off.

What we collect

By default, only anonymous usage statistics (see below). There is no sign-up, no account, no advertising and no tracking. We never sell or share your data.

Where your data is stored

Your games, guesses, scores, streak, the saved price snapshots and your settings are stored only on your device, in the app's private storage. They are removed when you uninstall the app or use Settings → Reset games and stats. Copy backup (Settings → Your data) copies them as text to your clipboard; the app never uploads it.

Prices

To build each day's game the app asks the Magmanet server (EU, Contabo) for the prices of that day's products: GET /v1/basket/item/<barcode> with a fixed area (Tel Aviv-Yafo). The request contains only the product's barcode and that fixed area. No location, account or identifier is sent, and the app has no location permission. The prices come from the price files Israeli supermarket chains publish by law; they may differ in store.

Update check

Once a day the app asks the Magmanet server whether a newer version exists (app name, version and how it was installed only; no identifiers, no IP address stored). If the server is unavailable it reads the public version file from GitHub Pages. You can turn this off in Settings.

Anonymous usage statistics

The app sends anonymous usage statistics over HTTPS (a short ping once a day; usage events a few times a day at most, batched) to Magmanet's own server in the EU (Contabo), not to Google or any other third party: app name and version, Android version, phone manufacturer and model, language, how the app was installed, a random install ID made by the app, and anonymous usage events (which screens and features are used, for how long, and each finished game's score). On the server the ID is hashed and no IP address is stored; raw data is deleted after 400 days. It is used only to count users and improve the app. It is on by default; turn it off in Settings ("Share anonymous usage statistics"), which stops sending and deletes the random ID from your phone.

Permissions

  • Internet: prices, the update check and the anonymous usage statistics.

No location, camera, microphone, contacts, storage, notification or sensor permissions.

Children

The app is not directed at children and collects no personal information from anyone.

Changes

If this policy changes, we'll update the date above and publish the new version at the same address.
